# 每日一学海报 Skill

用于制作力量发展集团「每日一学」工作日海报与节日主题海报的 Codex Skill。

## 包含内容

- `SKILL.md`：制作流程、排版和内容规则。
- `references/`：月度制作规范与已确认批次设置。
- `assets/`：集团 Logo 与关注二维码。
- `scripts/`：本地 PNG 海报渲染脚本。

## 使用方式

将本目录放入 Codex 的 `skills/` 目录后，提出明确日期或月份、学习主题、节日要求和可选署名即可生成。署名为空时不会显示。

2026 年已确认批次规则见 `references/confirmed-2026-batches.md`：10 月日更卡带指定署名，11 月成本意识卡不署名。

## 输出规则

默认输出 PNG；仅在周一至周五生成日更卡。节日卡的视觉素材与节日主题匹配，二维码下方的“扫码关注”会根据背景色自动保持清晰可见。
